# gabservicioautomotriz.com

Sitio de GAB Servicio Automotriz. HTML y CSS sin dependencias, listo para GitHub Pages.

- `index.html`: todo el contenido. Busca "PENDIENTE" para lo que falta.
- `css/styles.css`: colores y tipografía hasta arriba, en `:root`.
- `img/`: logo, fotos y favicon.
- `CNAME`: dominio para GitHub Pages.
